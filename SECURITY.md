# Security Policy

## Supported Versions

ProcessTrust Auditor is a PowerShell project I developed to help examine Windows processes, digital signatures, and network activity.

| Version | Supported |
|---|---|
| 1.3 | Yes |
| Earlier versions | No |

## Reporting a Security Issue

If you find a security issue with ProcessTrust Auditor, please report it privately through GitHub's vulnerability reporting feature, if available.

Include what you found, how to reproduce it, and any potential security risks.

Please avoid posting vulnerabilities publicly before I've had a chance to review them.

## Safe Usage

A few things to keep in mind when using this tool:

- Review the script before running it.
- Only run it on computers you own or have permission to inspect.
- Be careful when sharing audit results since they may contain system information.
- Understand what you're changing if you need to adjust PowerShell execution policies.
- Remember that an unsigned process or unusual network connection doesn't automatically mean something is malicious.

## Updates and Maintenance

This is a personal cybersecurity project that I'm continuing to learn from and improve.

I'll review reported issues when I can and make updates as needed.
